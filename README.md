# Master's Thesis – Portfolio Optimization with Machine Learning

This repository contains the code developed for my Master's thesis on portfolio optimization using machine learning techniques. The project combines quantitative finance, predictive modeling, and Python-based data analysis to evaluate and compare different portfolio construction approaches.

## Repository Structure

- `scripts/` – Python scripts for data processing, model training, portfolio construction, and performance evaluation.
- `manuscript/` – Final thesis manuscript.

## Note

The datasets used in this project are not included in this repository. If you are interested in accessing the data, please feel free to reach out.
