# Scripts

This folder contains the Python scripts developed for my Master's thesis on portfolio optimization using machine learning techniques. The scripts follow the workflow of the project, from data preparation to model evaluation and visualization.

## Script Overview

| Script | Description |
|--------|-------------|
| **01_data_tokenizer.py** | Downloads, cleans, and tokenizes the raw textual data used throughout the project. |
| **02_polarity_mc.py** | Computes sentiment (polarity) measures using the Monte Carlo methodology described in the thesis. |
| **03_bl.py** | Implements the Black–Litterman model and generates return forecasts based on sentiment signals. |
| **04_equity.py** | Constructs and evaluates the portfolio strategies, including benchmark and sentiment-enhanced portfolios. |
| **05_plots_tables.py** | Produces the figures and tables presented in the thesis manuscript. |
| **06_model_perf.py** | Evaluates and compares the predictive performance of the machine learning models. |
